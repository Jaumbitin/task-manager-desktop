# Interface
A organização da lista e a navegação lateral usam o Todoist como referência:
https://www.todoist.com/help/todoist/get-started/use-the-inbox-in-todoist-HwHvYErS

A interface tem fundo claro, tons neutros e uma cor de ação. As tarefas usam linhas compactas, conclusão por botão circular, filtros com estado ativo e uma ação para criar a primeira tarefa no estado vazio. Login e cadastro seguem a mesma identidade.

As imagens em docs/images usam dados sintéticos de teste visual. O teste FxmlSmokeTest carrega login e painel, aplica o CSS e valida busca e filtros. Não representam uma conta de produção.
